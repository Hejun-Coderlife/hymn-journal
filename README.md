# 银行日记账拆分（赫眉 HYMN 财务工具）

把「2026年银行日记账.xlsx」汇总表里每个 sheet 转成「导入模版-日记账」格式（给唐小琪导入用）。

- 改 `src.html`，然后 `python3 build.py` → `dist/银行日记账拆分.html`（单文件，库+logo 全内嵌，双击/离线/Windows 都能用）
- 源表结构：第 17 行表头「日期|摘要|(空)|收入金额|支出金额|收支账户」在 J–O 列；程序按「日期」后紧跟「摘要」自动找表头
- 输出：日期/摘要/收入（贷方）/支出（借方）/余额(空)/对方户名=收支账户/备注(空)/凭证模板编号(空)；宋体11、表头加粗细框、冻结首行、筛选
- 单独文件的 sheet 名保持「导入模版-日记账」；合成一个文件时 sheet 名=表名
- **汇总表**（2026-11-12）：每天 × 每个账户一行（笔数/收入/支出/差额），日期是真日期可按年月日筛选；第1行「筛选后合计」用 SUBTOTAL 跟着筛选变，第2行表头浅灰加粗+冻结+筛选。页面清单第一行就是「汇总」，可勾掉不导出、点开预览。合一时是第一个 sheet，分文件时 zip 里多一个 汇总.xlsx
- 风格照 hymn-poster（白底/发丝线/直角/近黑按钮）
- 命令行版：~/Projects/日记账拆分.py（结果已与网页版逐格比对一致）

网站：https://hejun-coderlife.github.io/hymn-journal/ （index.html 由 build.py 生成；数据只存浏览器 IndexedDB，不上传）
